# Hospital Directories OCR → CSV


Testing out a fully LLM coded approach. All files written by copilot+codex+gemini

## Quick start

cirrascale_ocr.py runs the OCR commands through the olmocr endpoint hosted by Cirrascale.
convert_to_csv.py is a helper script from converting md html tables to csv.

alternative updated approach is to use gemini_pipeline.py as a single run going from pdf file to csv outputs.
